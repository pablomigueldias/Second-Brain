
Considere os conjuntos A = {x ∈ Z ∣ −2 ≤ x ≤ 3} e B = {x ∈ Z ∣ x ≤ 0}. Logo, o conjunto A∩B é:

A) {−2,−1,0}
B) {−2,−1}
C) {−2,−1,0,1}
D) {−1,0,1}


>[!success] Alternativa correta: A
>{−2,−1,0}


## Entendendo o Universo ($\mathbb{Z}$)

Ambos os conjuntos trazem a informação $x \in \mathbb{Z}$.

- O símbolo  $\mathbb{Z}$ representa o **Conjunto dos Números inteiros**
- Ou seja: $\dots, -3, -2, -1, 0, 1, 2, 3, \dots$
- **Atenção**: Número negativos são inteiros e o **zero também é um inteiro**!

## Traduzindo o Conjunto A

O enunciado diz: $A = \{x \in \mathbb{Z} \mid -2 \le x \le 3\}$

- **Lê-se**: "x pertence aos inteiros, tal que x é o maior ou igual a -2 **E** menor ou igual a 3".
- O sinal $\le$ significa que o limite **faz parte** do conjunto. Se fosse apenas $<$, o limite estaria de fora.
- Listando os elementos de A:

$$A = \{-2, -1, 0, 1, 2, 3\}$$

## Traduzindo o Conjunto B

O enunciado diz: $B = \{x \in \mathbb{Z} \mid x \le 0\}$

-  **Lê-se**: "x pertence aos inteiros, tal que x é menor ou igual a zero".
- Novamente, tempos o "ou igual", então o zero entra.
- Listando os elementos de B:

$$B = \{\dots, -3, -2, -1, 0\}$$

## A Operação Solicitada ($A \cap B$)

O símbolo $\cap$ significa **Interseção**.

- A interseção quer saber: "Quais elementos existem no Conjunto A **E** também existem no Conjunto B ao mesmo tempo?"
- Olhando para as nossas listas: $A = \{ \mathbf{-2}, \mathbf{-1}, \mathbf{0}, 1, 2, 3 \}$ $B = \{ \dots, -3, \mathbf{-2}, \mathbf{-1}, \mathbf{0} \}$

Os elementos que se repetem em ambos são exatamente $-2$, $-1$ e $0$.

Portanto:

$$A \cap B = \{-2, -1, 0\}$$

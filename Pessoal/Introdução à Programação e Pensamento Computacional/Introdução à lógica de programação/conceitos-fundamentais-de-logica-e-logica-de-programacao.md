# Conceitos Fundamentais de Lógica e Lógica de Programação

> [!resumo] Do que se trata
> Apresenta a definição de problema como um desvio de percurso que impede de atingir um objetivo e a lógica como instrumento para solucionar essa questão. Explora as origens filosóficas da lógica através de dedução, indução, hipótese e inferência para organizar o pensamento e determinar o que é verdadeiro. Demonstra a aplicação da lógica na computação e na programação como a organização estruturada e assertiva de instruções em algoritmos para que computadores executem tarefas.

## Para lembrar

- **Um problema é caracterizado como uma questão ou desvio de percurso que impede atingir um objetivo com eficiência e eficácia, possuindo múltiplas soluções possíveis.**
- **Formalmente na filosofia, a lógica trata de operações intelectuais como dedução, indução, hipótese e inferência para determinar a veracidade das coisas em um contexto.**
- **Na computação, a lógica consiste na organização e no planejamento de soluções assertivas em um algoritmo para viabilizar a implantação de um programa.**
- **Diferente dos seres humanos, que usam a lógica de forma intuitiva, os computadores dependem de instruções detalhadas e sequenciais para executar qualquer ação.**
- **Aprender a programar computadores desenvolve o raciocínio lógico e o pensamento computacional para estruturar o pensamento de forma mais objetiva.**

- Como a lógica se aplica no contexto da computação e construção de algoritmos?

### O que é um Problema?

A lógica surge para solucionar a resolução de algum problema.

Um problema é uma questão, uma proposta duvidosa, um objeto de discussão que pode ter inúmeras soluções.

### Definição de Lógica (Geral)

Utilizando uma definição mais formal, o que é lógica?

É um problema, é uma questão que foge de uma determinada regra. Ou melhor, é um desvio de percurso que impede de atingir um objetivo com eficiência e eficácia.

Portanto, o problema é o desvio de percurso, e a lógica é o que nos auxilia a resolver esse problema.

### Definição Formal de Lógica

Uma definição formal de lógica parte da filosofia, que trata das formas de pensamento em geral:

*   Dedução;
*   Indução;
*   Hipótese;
*   Inferência;
*   Operações intelectuais que visam a determinação do que é verdadeiro ou não.

É uma forma de pensamento estruturada que nos auxilia a determinar o que é verdadeiro ou não dentro de um contexto. Ela, sim, vai nos auxiliar a resolver problemas.

A lógica é, portanto, uma organização coesa de raciocínio onde conseguimos ordenar a sequência que segue convenções e que nos permite desencadear acontecimentos. Ela fornece uma ordenação, um sentido, o que é verdadeiro em um determinado contexto ou para uma determinada situação.

### Lógica na Computação

Puxando a definição para o nosso lado da computação, a lógica é a organização e o planejamento das soluções assertivas em um algoritmo, a fim de viabilizar a implantação de um programa.

Se ela é uma ordenação coesa, uma organização com o fim de resolver um problema, é uma forma de raciocínio que segue convenções e que desencadeia acontecimentos. Nosso objetivo é um programa, é executar aquele programa. A lógica vai fornecer para nós essa organização das instruções mais assertiva em relação ao algoritmo, viabilizando o nosso programa.

Para finalizar, você percebe que esta definição se aplica ao seu cotidiano? Vamos pensar. Você tem uma sequência de instruções, e essas instruções são geradas, são baseadas em ações. Essas ações, por sua vez, estão relacionadas a uma ação maior, e essa ação principal é o seu alvo, é o que você quer alcançar, o seu objetivo. Por exemplo, fazer o seu café da manhã: acordar, tomar o seu cafezinho. Como será esse jogo? Vamos ver.

`⏱ 04:40`

O café, olhem só como ele se encaixa nisso. Qual é o seu objetivo? Tomar o café. Para isso, você precisa fazer o quê? Um algoritmo, uma instrução passo a passo para fazer o seu café e depois tomar. Para isso, você precisa de uma organização, de um planejamento das instruções de uma maneira assertiva, para que você consiga produzir o seu café, fazer o seu café e, então, executar o seu programa.

### Lógica de Programação

Nós podemos prever comportamentos. Nós utilizamos a lógica de uma maneira intuitiva, mas os computadores não. Muitas vezes, temos a parte da falta de costume, mas os computadores precisam de instruções detalhadas para que possam executar os mesmos passos que nós. É para isso que utilizamos a lógica na programação.

Steve Jobs tem uma frase interessante que eu trouxe aqui para vocês: "Todos nesse país deveriam aprender a falar a programação de computador, programar no computador, porque isso ensina como pensar."

Por quê? Porque você utiliza o pensamento computacional, raciocínio lógico, lógica, que está atrelada a raciocínio lógico. Você aprende a pensar de uma maneira mais objetiva. A lógica é usada a fim de resolver problemas, a fim de executar ações e chegar a um determinado objetivo.

Ele diz: "Everybody in this country should learn how to program a computer." Sim, todos deveríamos aprender a programar um computador.

### Word 1: Fork (no context de IDE)

**English:** fork
**Portuguese:** bifurcação / cópia

**Category:** 
- #IDE #Software #Development

**Definition (Technical):**
When a software project creates a new version based on existing source code. In Cursor's case, it's a fork of Visual Studio Code.

**Example from Course:**
"Cursor is a **fork** of Visual Studio Code, which means it behaves almost the same as VS Code in terms of interface..."

### Word 2: Syntax Highlighting

**English:** syntax highlighting
**Portuguese:** destaque de sintaxe

**Category:**
- #IDE #Features #CodeEditing

**Definition (Technical):**
A feature in code editors that colors different parts of the code differently (keywords in blue, strings in green, etc.) to make code easier to read.

**Example from Course:**
"Traditionally, an IDE or code editor offers aids such as **syntax highlighting**, basic code auto-completion, debugger, etc."

**Example in Code:**
```python
# Green = string
message = "Hello"

# Blue = keyword
if message:
    print(message)  # Purple = function
```

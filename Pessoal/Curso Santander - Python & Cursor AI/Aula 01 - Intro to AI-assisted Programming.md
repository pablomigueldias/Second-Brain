



# Understanding

## Exemple

**Texto Original:** "In recent years, development environments have **evolved** from simple text editors to **full-fledged** intelligent IDEs."
- **evolved from:** evoluíram de (passado, mudança de estado).    
- **full-fledged:** completo, totalmente desenvolvido. _(Ex: O Cursor não é só um editor, é um full-fledged IDE)._   

**Texto Original**: With the arrival of artificial intelligence, it is now possible to have integrate code assistants that write, understand and improve programs.

- **the arrival**: a chegada
-  **Improve programs**: melhorar programas

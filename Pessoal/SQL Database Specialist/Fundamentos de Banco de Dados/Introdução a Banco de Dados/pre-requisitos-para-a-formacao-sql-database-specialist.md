## Conteúdo

### Pré-requisitos da formação

Algo que vocês podem estar se perguntando: tem algum pré-requisito para começar essa formação? O assunto é abordado do zero ao tema mais avançado.

Contudo, se você procurar em grade de faculdade, banco de dados não é algo que é dado no primeiro período. Passamos por algumas matérias antes de começar a ter o primeiro contato com banco de dados e, consequentemente, com modelagem de dados.

Dessa forma, eu trouxe alguns conhecimentos prévios que serão interessantes para vocês terem maior aproveitamento da formação. Porque, na hora que eu estiver falando de arquitetura de três camadas com vocês, se não tiverem uma noção de arquitetura de computadores, vai ficar muito abstrato, muito complicado de entender.

É possível de acompanhar? Sim. Se você não tiver esse conhecimento, pode fazer a formação. O que pode acontecer é que você leve um pouco mais de tempo para entender alguns conceitos, e aí precisa procurar.

Outra possibilidade é, se não tiver esses conhecimentos, você pode procurar por demanda. Quando formos falar de arquitetura de banco de dados, vocês podem procurar temas específicos voltados para essa matéria, porque a própria matéria de arquitetura de computadores é a matéria de um semestre na faculdade.

Novamente, o assunto é abordado do zero, considerando que vocês nunca tiveram contato com o SGBD. Contudo, existem diversos outros conceitos atrelados a essa matéria.

### Conhecimentos prévios recomendados

Para ter maior aproveitamento da formação, alguns conhecimentos prévios são interessantes:

-   **Lógica e pensamento computacional:** São super bem-vindos. A lógica de programação já vai te dar um tipo de raciocínio voltado para a resolução de problemas, o que proporcionará uma melhor compreensão de como o SGBD está estruturado e qual o raciocínio para a criação das *queries*.
-   **Noções de arquitetura de computadores:** Essencial para entender melhor como um SGBD funciona, já que ele é um software modular. É preciso compreender um pouco de como ele realmente funciona como um todo.
-   **Noções de sistemas operacionais:** Com elas, vocês conseguirão absorver melhor o conteúdo que está sendo passado dentro da formação.
-   **Noções de matemática básica:** O `SQL`, o banco de dados relacional, é baseado na teoria de conjuntos. É preciso entender pelo menos essa teoria para conseguir perceber melhor a aplicabilidade do SGBD.

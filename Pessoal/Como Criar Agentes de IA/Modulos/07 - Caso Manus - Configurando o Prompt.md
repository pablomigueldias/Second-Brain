# Caso Manus — Configurando o Prompt

> Em uma frase: você vai ver como escrever um bom prompt para o agente — definindo papel, tarefa, regras e formato de entrega.

## 👋 Vamos começar
Um agente é tão bom quanto a instrução que recebe. Nesta aula o instrutor mostra o
**prompt** que ativa o Manus. Vale estudar a *estrutura* dele — é um modelo que
você pode reaproveitar.

## 🛠️ Anatomia do prompt (passo a passo)
1. **Defina o papel (persona).** "Você é um líder sênior em engajamento de
   stakeholders e comunicação para grandes projetos de energia renovável." → dá
   contexto e tom de especialista ao agente.
2. **Defina a tarefa.** Criar o plano de engajamento e o plano de comunicação do
   projeto.
3. **Crie uma regra de clarificação.** "Se faltar informação crítica, faça até **6
   perguntas curtas de múltipla escolha** antes de prosseguir; senão, siga direto."
   → evita que o agente "chute" suposições.
4. **Forneça os dados do projeto.** Os detalhes do parque eólico (da aula anterior).
5. **Especifique os entregáveis e o formato.** Plano de engajamento com 6 itens
   (mapa, registro, riscos…) e plano de comunicação (segmentação, arquitetura de
   mensagens, matriz, plano de crise). Mantenha **prático**.
6. **Anexe e mande executar.** Como o texto é grande, ao colar ele entra como um
   **arquivo de texto**; depois basta pedir "execute as instruções do documento em
   anexo".

> 💡 **Guarde isto:** um bom prompt de agente tem **papel + tarefa + regras +
> dados + formato de saída**. A regra das "até 6 perguntas" é um truque poderoso
> para o agente esclarecer dúvidas em vez de inventar.

---

## 🧠 Por que isso importa pra você
Essa estrutura de prompt serve para **qualquer** agente, não só o Manus. Quando
você define papel, regras e formato, a qualidade do resultado dispara.

## 📌 Resumo pra fixar
- Estrutura: **papel → tarefa → regra de clarificação → dados → formato**.
- "Faça até N perguntas se faltar algo" = freio contra suposições erradas.
- Texto longo entra como arquivo anexo; peça para executar as instruções.

## 🗝️ Palavras novas (do jeito simples)
- **[[Prompt]]** — a instrução que você dá ao agente/IA.
- **[[Persona (prompt)]]** — o papel que você atribui à IA ("você é um especialista em…").
- **[[Prompt de clarificação]]** — pedir que a IA faça perguntas antes de agir.

## ✅ Teste-se (pra enraizar)
1. **P:** Quais os 5 elementos de um bom prompt de agente? → **R:** Papel, tarefa, regra de clarificação, dados e formato de saída.
2. **P:** Para que serve a regra das "até 6 perguntas"? → **R:** Para o agente esclarecer dúvidas em vez de assumir suposições erradas.
3. **P:** Por que definir uma persona? → **R:** Dá contexto e tom de especialista, melhorando a qualidade da resposta.

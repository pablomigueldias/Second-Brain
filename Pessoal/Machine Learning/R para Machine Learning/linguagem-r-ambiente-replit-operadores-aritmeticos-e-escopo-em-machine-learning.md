### Operadores Aritméticos e Funções

Em relação aos operadores aritméticos:

- Adição: se fizermos `1 + 1`, vai retornar o valor `2`.
- Multiplicação: se fizermos `2 * 2`, vai retornar o valor `4`.
- Divisão: se fizermos `8 / 4`, vai retornar o valor `2`.

É a base da matemática, o que já vimos para Python, para C e outras linguagens. A linguagem R também trabalha muito bem com funções; a base dela são as funções matemáticas e conseguimos trabalhar muito bem com essa parte.

Vamos dar um exemplo: quero representar uma fração matematicamente. Vinte mais sete dividido por três, e tudo isso elevado ao quadrado. Como ficaria? 

Vamos fazer esse exemplo: ficaria `(20 + 7) / 3`, e todo mundo ao quadrado, colocando o quadrado lá fora: `((20 + 7) / 3) ^ 2`. O valor que vai gerar de retorno é `81`. 

É uma função bem simples, como se você estivesse em uma calculadora do Windows, jogando seus valores e esperando o retorno. É claro que não é só isso: a ferramenta junto com essa linguagem vai muito além disso, principalmente...

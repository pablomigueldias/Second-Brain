# Projeto Final — Modelo de Machine Learning

> [!info] Sobre este módulo
> Este é o **mapa de conteúdo (MOC)** do módulo **14 — Projeto Final**. É a **atividade prática** que fecha o curso: construir, do zero, um modelo de Machine Learning sobre o **Adult Income Dataset**, otimizando para a melhor **performance** (métrica principal: **F1 Score**).

---

## Roteiro de Estudo

- [[01 - Desafio e Roteiro do Projeto]] — O dataset, os arquivos (train/validation/test), os requisitos obrigatórios e um passo a passo para executar o projeto.

---

## O Desafio em uma Frase

> [!abstract] Objetivo
> Treinar um classificador que prevê se a **renda (income)** de uma pessoa é `<=50K` ou `>50K`, maximizando o **F1 Score**, com pré-processamento, engenharia de atributos, tuning documentado e **XAI** para explicar o modelo.

---

## Conceitos que este projeto integra

> [!summary] Tudo se junta aqui
> - **Pré-processamento** — NANs, outliers (base de [[Fundamentos]]).
> - **Engenharia de atributos** — codificação de categorias, escala, seleção.
> - **Modelagem e tuning** — algoritmos de [[Algoritmos de Machine Learning]].
> - **Avaliação** — F1 Score e demais métricas.
> - **Explicabilidade** — [[06 - Machine Learning Explicável (XAI)/00 - Índice|XAI]].

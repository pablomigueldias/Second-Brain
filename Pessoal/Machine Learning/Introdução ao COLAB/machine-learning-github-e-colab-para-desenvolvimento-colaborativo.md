# Machine Learning: GitHub e Colab para Desenvolvimento Colaborativo

> [!resumo] Do que se trata
> Esta aula explora a importância de ambientes colaborativos como GitHub e Colab para o desenvolvimento em Machine Learning, enfatizando o compartilhamento de código e a evolução constante do estado da arte. Ela detalha como essas plataformas contribuem para a carreira profissional e facilitam a utilização e melhoria de algoritmos existentes. A nota também aborda a necessidade de documentação e a praticidade do Colab para execução de projetos de ML.

## Para lembrar

- **Na computação, nada se cria, tudo se copia; algoritmos prontos estão disponíveis, mas podem ser customizados e melhorados a partir do estado da arte.**
- **O estado da arte em Machine Learning evolui constantemente, com novos algoritmos e redes surgindo diariamente, exigindo acompanhamento contínuo.**
- **Projetos no GitHub devem ter documentação clara para facilitar o entendimento e uso por outros desenvolvedores, evitando trabalho extra para quem for consumir o código.**
- **Colab permite executar algoritmos de Machine Learning de forma prática, superando problemas de dependências e sistemas operacionais locais.**

## O que esta nota responde

- Qual a importância do GitHub e Colab para o desenvolvimento em Machine Learning?
- Como o compartilhamento de código em plataformas colaborativas impacta a carreira e o avanço tecnológico?
- O que é o "estado da arte" em Machine Learning e como ele se relaciona com o desenvolvimento colaborativo?

### GitHub

GitHub é um ambiente onde a gente vai hospedar nosso projeto em nuvem. Isso ajuda tanto a compartilhar nosso conhecimento com outras pessoas, quanto a organizar o que a gente desenvolve.

Quantos já desenvolveram algo, usaram, e depois pensaram: "Nossa, eu já desenvolvi um `código` desse e preciso de novo"? Aí falam: "Vixe, deve estar em algum HD", e perdem porque têm preguiça de ir lá procurar.

Este ambiente é muito importante para que a gente utilize para compartilhar os nossos projetos e para que a gente tenha ali uma ferramenta para auxiliar o que a gente desenvolve a ficar bem organizado e documentado.

Vou mostrar um pouco do Collab. É algo bem simples, não vou dedicar tanto tempo a isso.

Elas conseguem deixar, por exemplo, aqui no caso da Dio, os exemplos feitos nos cursos. Aí o aluno pensa: "Ah, preciso ver como foi a implementação. Só olhando o vídeo não dá certo. Eu preciso abrir o `código`, eu quero ver, eu quero executar."

A pessoa vem aqui, por exemplo, no `lab de padrões de projetos Spring`. Ela entra aqui dentro desse projeto e consegue ver tudo que tem aí dentro.

Aqui também tem as linguagens que estão no top: `JavaScript`, `Java`, `C Sharp`, `HTML`. Essas são as linguagens mais fortes aqui dentro desse grupo de pessoas. Mas no GitHub também temos outras linguagens e outros tipos de projetos.

### Documentação Essencial

Geralmente, há uma documentação. Essa documentação é muito importante, e poucos projetos fazem isso. Não adianta nada subir um código que não está documentado. A pessoa que for usar meu código terá mais trabalho para entender como ele funciona do que para implementá-lo de novo. Isso é muito errado.

A documentação é muito importante. Ela deve dizer qual a versão do `Python` que eu preciso rodar, qual a versão do `TensorFlow`, qual a biblioteca que precisa, e quais as dependências que eu tenho que colocar para rodar esse algoritmo. Vocês podem ver que tudo é muito bem documentado.

### Integração com Colab

Há também os links. Conseguimos colocar um link para acessar esse algoritmo pelo Colab, como vimos. Eu clico aqui e acesso o Colab, rodando o algoritmo lá na plataforma do Colab.

Temos um link muito importante entre o GitHub e o Colab. Conseguimos compartilhar nosso código também na parte executável. Quando deixamos o link certinho do Colab, a pessoa não tem aquela dor de cabeça de: "Nossa, mas as dependências que eu instalei não deram certo. Será que é o meu sistema operacional? Qual é o problema que está acontecendo? Será que tem alguma coisa instalada que está dando um conflito?"

Eu consigo colocar o meu algoritmo lá no Colab para que a gente consiga executá-lo de uma forma mais prática. Praticamente, os projetos melhores documentados, todos têm acesso ao Colab.

### Subindo Conteúdo na Plataforma

A plataforma é bem simples para subir um código. Eu posso subir o que eu quiser aqui, praticamente:

Vocês vão escolher o que vão subir no projeto de vocês.

## Conteúdo

### Instalação do Sublime

Vamos começar pela instalação do Sublime, que é o software que usaremos para programar em Python. 

Existem várias ferramentas que podemos usar. Algumas pessoas programam diretamente em um editor de texto, apenas para codificar, e depois chamam o terminal para executar o código. No entanto, para quem está começando, é interessante ter uma tela de programação que faça a indentação do código corretamente. Por isso, é importante ter um software adequado, e o Sublime é um programa muito bom para programação em Python.

A instalação do Sublime é gratuita. Basta entrar no site `sublimetest.com`. Lá, há a versão para Windows, para Mac e para Linux:

- **Windows:** basta baixar o executável e avançar na instalação, de forma bem simples.
- **Linux:** basta dar o comando `install`, baixar o software na base deles para Linux e fazer a instalação na máquina.

Tanto no Windows quanto no Linux e no Mac, a interface gráfica é a mesma. A tela inicial é sempre dessa forma, sendo um software ótimo para programar em Python.

### Interface do Editor e Primeiro Teste

Ao abrir o editor, podemos colocar o nosso `Hello World`. Costuma-se dizer que, ao começar em uma nova linguagem de programação, se não fizermos um `print` de um `Hello World`, teremos azar. 

Ao executar o nosso `Hello World`, ele mostra o `print` em uma interface com o usuário logo abaixo. É possível programar na parte superior e gerar a saída na parte inferior. Ele também mostra o tempo de resposta. 

É uma interface muito boa e tranquila de usar, pois aponta os erros existentes. Caso haja algum erro, ela indica a linha onde ele está sendo gerado e qual é o problema ocorrido. Ao inserir uma sintaxe inválida no código e colocá-lo para executar novamente, corrigimos o erro e o código é executado normalmente.

Essa é a interface que usaremos nas aulas. Quem preferir utilizar outra com a qual já esteja acostumado, não há problema.

### Configurando o Ambiente

No prompt de comando, ao digitar `python` e verificar a versão, a que estamos utilizando é a `3.10.4`. É recomendável que todos utilizem essa mesma versão para evitar divergências.

### Operações em Python

As operações em Python são bem parecidas com as da linguagem C. Nas operações aritméticas, temos:

- **Soma:** `3 + 3`, utilizando o sinal de mais (`+`).
- **Subtração:** `9 - 3`, utilizando o sinal de subtração (`-`).
- **Multiplicação:** `3 * 3`, utilizando o asterisco (`*`).
- **Divisão:** `9 / 3`, que resulta em 3, utilizando a barra normal (`/`).
- **Exponenciação:** utilizada para efetuar cálculos como 2 elevado a 2.

Após a instalação, conseguimos executar comandos diretamente pelo terminal e realizar algumas funções simples por lá. No entanto, o ideal é utilizar pelo menos um editor de texto para codificar. Depois, chamamos o arquivo pelo terminal para execução e visualizamos o resultado do algoritmo no próprio terminal.

### Visualização de Resultados

Caso estejamos trabalhando com uma detecção facial, por exemplo, surge a dúvida de como mostrar o resultado além do texto do terminal. Para exibir a face detectada na imagem, conseguimos gerar a imagem e plotá-la na tela por meio de uma interface gráfica.

### Ferramentas e Ambientes de Desenvolvimento

O Python dispõe de muitos recursos. O objetivo inicial é apresentar a instalação e os recursos da interface de programação do Sublime. 

Quem quiser utilizar outra interface de programação ou outra `IDE`, fique à vontade. O Sublime é uma ferramenta bem leve e simples de instalar.

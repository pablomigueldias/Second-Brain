# SciLab: Ferramenta para Modelagem e Programação em Machine Learning

> [!resumo] Do que se trata
> Esta aula apresenta o SciLab, um software matemático gratuito e poderoso, ideal para a área de Machine Learning e engenharia. É possível utilizá-lo para modelar problemas, realizar simulações e validar modelos matemáticos antes de implementar em linguagens como Python ou C. Além de ser útil para ML, o SciLab é amplamente utilizado em áreas como robótica, controle de veículos autônomos e estatística.

## Para lembrar

- **O SciLab é um software matemático gratuito, muito utilizado em engenharia da computação, elétrica, eletrônica e ciência da computação.**
- **Embora seja um software matemático, é possível codificar estruturas condicionais, estruturas de repetição, criar variáveis e usar operadores lógicos no SciLab.**
- **O SciLab permite gerar soluções com modelagens matemáticas práticas, possibilitando testar, fazer simulações e validar modelos.**
- **O SciLab é semelhante ao MATLAB, sendo uma alternativa gratuita e poderosa para projetos de Machine Learning, robótica e levantamento de dados estatísticos.**

Olá. Meu nome é Diego Bruno e hoje vamos ver uma ferramenta muito poderosa para a área de Machine Learning: o SciLab.

Essa ferramenta é gratuita. Vamos ver como instalá-la no nosso computador e também os módulos que precisamos para o nosso curso, pois vamos começar a programar para Machine Learning utilizando essa ferramenta. Conheceremos um pouco mais sobre esse tipo de programação.

#### O que é o SciLab?

Como eu disse, ele é gratuito e muito utilizado para a área de engenharia da computação, engenharia elétrica, engenharia eletrônica e também na área de ciência da computação.

É um software matemático. Embora seja um software matemático, nele podemos codificar estruturas condicionais e estruturas de repetição. Podemos criar variáveis e temos operadores lógicos. Por isso, é uma ferramenta muito poderosa, principalmente para apresentar os resultados obtidos nos modelos de Machine Learning.

Com ele, conseguimos gerar soluções com modelagens matemáticas práticas. Podemos testar, fazer simulações e, por meio da nossa modelagem, fazer simulações e validar o nosso modelo. Depois, podemos partir para uma programação mais direcionada para o nosso problema. Por exemplo, eu posso modelar meu problema todo aqui, validar ele e depois ir para uma linguagem `Python` ou uma linguagem `C`, que vai rodar direto no meu sistema real.

#### Aplicações e Mercado

Muita gente pensa que o SciLab é apenas uma ferramenta para estudantes, para pessoas acadêmicas, professores ou pesquisadores. Isso não é verdade.

Eu já tive contato com grandes empresas que utilizam essa ferramenta, seja o SciLab (que é gratuito) ou o `MATLAB` (que é pago), para os projetos que desenvolvem. Isso inclui:

- Machine Learning;
- Controle de veículos autônomos;
- Robótica terrestre e aérea;
- Levantamento de dados estatísticos.

É uma ferramenta muito poderosa e pouca gente sabe usar. Quem fizer este curso terá um diferencial no mercado. Muitas empresas procuram um funcionário que saiba usar essa ferramenta.

Aprender a usar o SciLab também ensina o `MATLAB`, porque são praticamente iguais. O `MATLAB` tem algumas coisas a mais porque eles investem muito em recursos por ser um software pago, mas o SciLab nunca deixou a desejar em projetos.

#### Definição do SciLab

O SciLab é um software científico para computação numérica, semelhante ao `MATLAB`. Ele fornece também um ambiente poderoso para a área computacional, de forma aberta, para aplicações científicas e de engenharia. E, como eu disse, ele é disponível gratuitamente para várias plataformas como `Windows`, `Linux` e `Mac OS`.
